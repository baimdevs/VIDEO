# Geografi Kelas X — Reels

Video belajar vertikal 720 × 1280 (9:16), 60 detik, dengan animasi motion graphics, materi berbahasa Indonesia, dan musik latar sintetis. Kredit video: Rikaya Nurcahya.

## Render

```bash
npm install
npm run render
```

MP4 hasil render disimpan sebagai `geografi-kelas-10-rikaya-nurcahya.mp4`.

Materi mencakup pengertian geografi, lima fenomena geosfer, tiga pendekatan geografi, dan contoh penerapannya pada banjir perkotaan.
